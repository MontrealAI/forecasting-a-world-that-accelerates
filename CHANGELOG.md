# Changelog

All notable changes are recorded here. Dates use ISO 8601.

## [2.0.0] — 2026-07-28 — Ceiling Edition

### Added

- Complete end-to-end probabilistic forecasting engine and `fwta forecast` command.
- Strict v2 input, output, and registry schemas.
- Residual-bootstrap model averaging with 50%, 80%, and 95% intervals.
- Downside, base, accelerated, and hazard-driven discontinuity scenarios.
- Generalized realization family with separate technical, demand, and transfer bottlenecks.
- Milestone crossing probabilities and date distributions.
- Standalone executive HTML report with embedded machine-readable output.
- Hash-chained prospective forecast registry and preregistration template.
- Proper scoring functions and prospective validation program.
- Frozen, source-linked METR and SWE-bench demonstrations with provenance records.
- Operational-evidence panel, empirical-case scripts, and generated paper figures/tables.
- 90% scientific-core branch-coverage gate, CycloneDX SBOM, expanded cross-platform CI, package-install smoke tests, pre-commit configuration, and release hardening.
- Updated formal paper, complete protocol appendix, legal boundaries, publication gates, and independent-replication procedure.
- Finalized byte-reproducible PDF metadata, dual-render PDF QA, clean wheel/source-distribution smoke tests, clean-room arXiv compilation, deterministic archives, and the browser-only GitHub publication guide.

### Scientific scope

Version 2.0.0 reaches the release-quality ceiling of the coordinated artifact against its declared engineering and documentation rubric. It provides mechanical verification, controlled mechanism tests, and source-linked historical demonstrations. Prospective calibration, independent replication, and decision validation must be earned over time and are not claimed by this release.

## [1.0.0] — 2026-07-28

### Added

- Initial formal paper, compact canonical model, complete prompt, schemas, reference code, controlled hindcasts, ablations, public METR excerpt, tests, provenance, and publication infrastructure.

### Important scope

Version 1.0.0 was a methods and reference-implementation release. Its controlled results tested identification and mechanics but did not constitute prospective validation.
