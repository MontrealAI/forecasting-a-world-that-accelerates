The model in one screen

The primary equation is memorable; its disciplined use requires evidence, comparable units, verification, explicit constraints, uncertainty, and recalculation.

Yₛ(t) = Bₛ(t) · min { Q₀ · exp[ ∫₀ᵗ gQ,ₛ(u) du ], Mₛ(t) · Dₛ(t) · Uₛ(t) } Realized outcome = residual bottleneck × min(technical capacity, absorptive demand)
Version 2.0.0 extension. The engine also supports a generalized realization family with separate technical, demand, and transfer bottlenecks and optional partial substitution. The hard minimum remains the transparent default.

Run a complete forecast

The only mandatory inputs are a well-defined target, dated observations, a forecast horizon, and scenario/model settings conforming to the schema.

Install

Create a Python 3.11+ environment and install the package with development dependencies.

Copy the reference input

Start from protocol/v2/examples/canonical-reference-input.yaml and replace the controlled values with your evidence.

Run

Use fwta forecast to generate a validated JSON forecast and standalone HTML report.

Register before resolution

Append consequential forecasts to the hash chain before outcomes are known, then score them after maturity.

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'

fwta forecast protocol/v2/examples/canonical-reference-input.yaml \
  --schema protocol/v2/input.schema.json \
  --output results/ceiling/reference-forecast.json \
  --report results/ceiling/reference-forecast.html \
  --output-schema protocol/v2/output.schema.json
