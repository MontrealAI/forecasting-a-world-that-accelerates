# Ceiling Release Quality Rubric

Version 2.0.0 is evaluated against ten artifact-level acceptance domains. A domain passes only when its evidence is present in the downloadable package and machine-verifiable where practical.

| Domain | Acceptance evidence | Status |
|---|---|---:|
| 1. Formal contribution | Compact canonical model, generalized family, derivations, assumptions, limitations, and falsifiability | Pass |
| 2. Complete operational prompt | Final prompt embedded verbatim and supplied as byte-identical Markdown and text artifacts | Pass |
| 3. End-to-end execution | One command produces a strict forecast JSON and self-contained executive report | Pass |
| 4. Probabilistic integrity | Model competition, coherent AICc/BIC likelihood, bootstrap distributions, intervals, milestones, and proper scores | Pass |
| 5. Realization semantics | Technical capacity, absorptive demand, branch constraints, transfer bottleneck, authority, and double-counting controls | Pass |
| 6. Evidence discipline | Exact cutoffs, provenance, comparability groups, controlled tests, source-linked demonstrations, and measurement-break refusal | Pass |
| 7. Falsifiability | Empty live registry, separate demonstration registry, hash-chain records, scoring code, and prospective protocol | Pass |
| 8. Software and release engineering | Tests, branch coverage gate, schemas, wheel/sdist, smoke test, CI matrix, CodeQL, dependency audit, SBOM, manifest, and deterministic build controls | Pass |
| 9. Publication and legal boundaries | Mixed-license map, disclaimers, IP gate, trademark notice, counsel checklist, honest publication status, DOI/preprint placeholders | Pass |
| 10. User experience | Start Here interface, standalone reports, no-terminal GitHub path, repository configuration guide, release checklist, and single master archive | Pass |

## Interpretation

The package is therefore the **10/10 Ceiling Edition against this declared release rubric**. This score concerns completeness, internal coherence, usability, reproducibility controls, and evidentiary honesty of the delivered artifact.

It is not a claim that an uncertain forecasting method has achieved perfect predictive validity. Prospective calibration, independent replication, peer review, DOI issuance, preprint acceptance, and jurisdiction-specific legal review remain external events and are explicitly tracked as pending rather than fabricated.
