# Forecasting a World That Accelerates — v1.0.0

This founding release publishes the formal framework, complete executable prompt, machine-readable protocol, Python implementation, controlled hindcasts and ablations, workflow analysis, public-evidence demonstration, tests, compiled preprint, GitHub Pages source, and legal/governance package.

## Scientific scope

The release formalizes realized outcomes as the bottleneck-adjusted minimum of technical production capacity and absorptive demand, with technical growth decomposed across capability, cost decline, task-time compression, automation, effective parallelism, and verified reliability. It includes constrained, change-point, and recursive-improvement regimes.

Controlled synthetic experiments test whether the machinery can recover known regimes and expose omitted components. The compact public METR excerpt demonstrates the rolling-hindcast pipeline with explicit limitations. This release does not claim peer review, independent replication, universal external validity, or that every constituent mathematical method is novel.
