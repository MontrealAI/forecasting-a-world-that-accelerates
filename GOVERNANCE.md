# Governance and canonical authority

## Stewardship

The project is stewarded by ENTREPRISE TERMINATOR INTELLIGENCE INC. (MONTREAL.AI). Vincent Boucher is the founding author and protocol editor for version 2.0.0.

## Canonical artifacts

Only the following are canonical:

1. content on the protected `main` branch of `MontrealAI/forecasting-a-world-that-accelerates`;
2. signed version tags and corresponding GitHub releases;
3. a release manifest whose hashes match the artifacts;
4. an identified archival/preprint record linked by the release.

Forks, issue comments, drafts, model outputs, and unmerged branches are not canonical.

## Versioning

The repository uses semantic versioning for code and protocol releases:

- MAJOR: incompatible protocol, schema, or mathematical-semantics change;
- MINOR: backward-compatible model, evidence, or output extension;
- PATCH: correction, clarification, security fix, or reproducibility repair that does not intentionally change semantics.

The paper and full prompt carry the same release version. Corrections are never silently backdated. A corrected release receives a new version and changelog entry.

## Decision authority

Maintainers may accept or reject changes. No public vote, token, contribution, citation, fork, or use grants governance, ownership, equity, agency, or authority over MONTREAL.AI or the project.

## Scientific integrity

Material empirical claims require traceable sources and reproducible calculations. Synthetic demonstrations must be labeled. Negative results, model failures, corrected errors, and invalidated forecasts are preserved in release history rather than erased.
