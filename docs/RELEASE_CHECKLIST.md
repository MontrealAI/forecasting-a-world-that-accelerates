# Release checklist

## Scientific

- [ ] Target and units defined.
- [ ] Observations, inferences, assumptions, and controlled data separated.
- [ ] Evidence dates and source quality recorded.
- [ ] No future leakage in hindcasts.
- [ ] Candidate models and failure modes reported.
- [ ] Demand, bottlenecks, verification, authority, and critical paths not double-counted.
- [ ] Discontinuity scenario is conditional and constrained.
- [ ] Uncertainty and invalidation triggers reported.

## Engineering

- [ ] `make verify` passes cleanly.
- [ ] Schemas validate examples.
- [ ] Generated results are reproducible.
- [ ] Dependency audit reviewed.
- [ ] CodeQL and secret scanning reviewed.
- [ ] Paper compiles and rendered pages are inspected.
- [ ] Release archives are clean and checksummed.

## Rights and communications

- [ ] Ownership chain reviewed.
- [ ] Third-party material and licenses reviewed.
- [ ] Patent/public-disclosure timing reviewed.
- [ ] Trademark use reviewed.
- [ ] Disclaimer and reliance language present.
- [ ] No unearned “first,” “proven,” “guaranteed,” “audited,” or “fully protected” claim.
- [ ] DOI and preprint language matches actual status.
