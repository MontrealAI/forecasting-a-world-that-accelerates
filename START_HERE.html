Realized output is the lesser of technically deliverable capacity and absorptive demand after residual constraints. Version 2.0.0 also provides a generalized family with separate technical, demand, and transfer bottlenecks and optional partial substitution.

ONE-COMMAND ENGINE

Run a complete forecast

Create a clean Python environment.
python3 -m venv .venv source .venv/bin/activate python -m pip install -e '.[dev]'
Generate the complete probabilistic forecast and standalone report.
fwta forecast protocol/v2/examples/canonical-reference-input.yaml \ --schema protocol/v2/input.schema.json \ --output results/ceiling/reference-forecast.json \ --report results/ceiling/reference-forecast.html \ --output-schema protocol/v2/output.schema.json
Verify the complete release.
make verify

This rebuilds the scientific artifacts, validates schemas, runs tests and coverage, checks the registry, builds the paper and package, smoke-tests the installed wheel, scans release controls, and verifies the manifest.

PUBLICATION

Create and configure the repository safely

Complete the IP and counsel gate before disclosure. Read the counsel checklist and the patent/publication notice.
Create the repository privately first. Use the exact owner/name MontrealAI/forecasting-a-world-that-accelerates. Do not initialize another README, license, or .gitignore.
Run CI and configure protection. Require pull requests and passing checks; block force pushes; protect release tags; enable secret scanning, push protection, and CodeQL where available.
Publish only after owner authorization. Publish an immutable v2.0.0 release with artifact attestations, enable archival, submit the prepared preprint source, and add only identifiers that have actually been issued. A cryptographically signed tag additionally requires an authorized signing key.
